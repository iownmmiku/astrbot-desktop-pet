## 重跑

```powershell
# 先将两个仓库放在同一父目录，并在该目录创建 .venv、安装插件 requirements.txt。
.venv\Scripts\python -m unittest discover -s astrbot_plugin_desktop_pet\tests -v
# 另一个终端中启动联调服务，关闭时数据随临时目录清理：
.venv\Scripts\python astrbot_plugin_desktop_pet\tests\run_demo_server.py --port 19899
# 在桌面端目录：
$env:PET_INTEGRATION_URL = 'http://127.0.0.1:19899'
npm test
```

不设置 PET_INTEGRATION_URL 时，跨语言集成这一项会跳过。其余43项桌面测试可以独立运行。

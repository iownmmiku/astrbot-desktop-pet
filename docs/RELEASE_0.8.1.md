# 0.8.1 发行说明

桌面端 **0.8.1** 配套 AstrBot 桌宠插件 **0.5.1**，新增以下六项体验优化。Windows x64 用户可从[发行页](https://github.com/iownmmiku/astrbot-desktop-pet/releases/tag/v0.8.1)下载 `AstrBotDesktopPet-0.8.1-win-x64.exe`；插件请同时升级到 0.5.1，以获得完整冷却与请求恢复信息。

从源码运行时，在桌面端仓库执行 `npm ci`、`npm start`。本次更新记录见 [CHANGELOG](../CHANGELOG.md)，最终回归及构建范围见[本版验证记录](VALIDATION_0.5.1_0.8.1.md)；[历史验证记录](VALIDATION.md)保留 0.8.0 的验证范围。

## 1. 先测试填写内容，再保存连接

在「连接设置」填写服务器地址和令牌，点击「测试当前填写内容」。结果分别显示 HTTP 服务、令牌鉴权和 WebSocket 实时连接是否可用；服务不可达时，鉴权显示无法判断。

测试不会保存表单、切换服务器或断开现有连接。确认通过后再点击「保存并连接」。测试过程中修改地址或令牌，旧测试结果会失效，需要重新测试。

地址未改变时，令牌留空可使用已保存令牌；地址改变且未填写令牌时，测试与保存均不会沿用原服务器令牌，保存后原令牌会清除。新地址需要鉴权时，请重新填写对应令牌。表单会提示本次使用令牌的方式。

## 2. 在桌宠旁直接快聊

双击桌宠打开快聊小窗，单击仍为戳一戳。快聊使用与控制台相同的插件连接和请求恢复机制，不需要另配服务。

- `Enter` 发送，`Shift+Enter` 换行；输入法选词期间不会直接发送。
- `Esc` 或右上角关闭按钮收起小窗，本次运行中的草稿保留。
- 超时后可检查原请求结果，或使用同一请求 ID 重试。
- 右上角「⋯」、右键桌宠、桌宠旁花朵按钮及 `Ctrl+Alt+P` 可打开完整控制台。

快聊只展示有限的最近消息，不新增持久聊天记录。聊天上下文保存在插件内存中，插件重启后清空。

## 3. 读聊天记录时保持位置

控制台「聊聊天」和快聊小窗只在原本接近底部时跟随新回复。上翻阅读时保持位置，并出现新消息数量按钮；点击即可回到最新消息。可通过消息旁的「复制」按钮复制文本，快聊中主动发送消息会回到最新位置。

请求返回后，已切换到设置页或其他控件的输入焦点不会被拉回聊天框。原 ID 重试、实时回复去重及「清空显示」的原有行为保持不变。

## 4. 互动有处理反馈和冷却倒计时

投喂、摸摸、洗澡、睡觉、唤醒与戳一戳会显示处理中状态；插件返回冷却信息后，按钮显示剩余秒数并暂时禁用，结束后恢复。

倒计时根据桌面端接收时间计算，避免服务器时钟差异。睡眠与唤醒使用各自的冷却信息；睡眠状态变化后，同一个按钮切换为对应操作。请求失败时显示原因；冷却错误会更新对应按钮，客户端不会自动重复互动。

插件 0.5.0 未提供完整互动冷却快照时，倒计时信息可能不完整；建议同时升级到插件 0.5.1。

## 5. 控制启动方式与全屏陪伴

在新增的「启动与更新」页保存以下设置：

- **登录系统时启动**：目前仅支持 Windows 打包程序。源码运行以及设置了 `PET_DATA_DIR` 的独立测试环境不会写入系统启动项，开关会禁用并显示原因。便携 EXE 移动位置后，需要重新保存启动设置。
- **启动时收起控制台**：启动后保留桌宠和托盘，需要时再打开控制台。
- **全屏时安静陪伴**：目前使用 Windows 本地只读辅助进程检测全屏或演示状态。检测期间暂停桌宠显示和漫游，并抑制自言自语、平台推送；退出全屏后恢复。主动聊天及互动请求仍可处理。

页面分别显示系统启动项和全屏检测的运行情况。检测不可用时会提示原因，可继续使用「形象与窗口」中的手动免打扰、「安静一小时」或托盘开关。全屏检测不读取窗口正文，不安装系统服务。

## 6. 手动检查桌面端与插件版本

在「启动与更新」点击「检查更新」后，才会访问两端发行仓库。桌面端与插件分别显示当前版本、最新版本、更新说明或错误；一端检查失败不会遮住另一端结果。

桌面端 **0.8.1** 推荐配套插件 **0.5.1**，最低版本检查仍为 **0.5.0**。页面会提示插件是否达到最低版本要求；尚未连接或无法识别版本时明确显示未知，不判断为最新版本。最低版本检查不能保证未来所有插件版本的兼容性，也不代表较旧插件具备本版所有新增能力。点击对应发行页可自行核对、下载和替换程序；不会自动下载更新包或自动安装。

## 验证边界

2026-10-30 的发行前回归基线：插件 **45/45**，桌面端 **129/129**，没有失败或跳过项。桌面端计数包含两项真实 Python 插件 HTTP/WebSocket 联调，以及控制台 21 项、快聊与气泡 19 项、主进程 16 项、连接诊断及本地服务 24 项专项测试，不重复计数。

控制台与快聊使用真实 HTML/JS、模拟 preload 做 DOM 回归；主进程执行真实入口并模拟 Electron 和系统接口，覆盖窗口复用、安全 IPC、全屏恢复、后台启动、启动项保存失败回滚及新旧地址令牌隔离。跨语言联调使用插件的真实传输代码，AstrBot 与模型提供商为测试替身，没有调用真实模型或用户账户。

Windows 全屏检测辅助进程已实际启动并返回有效状态，随后正常关闭。Electron 原生桌宠窗口已显示；快聊及所有控制台页面未完成完整实机端到端验证。测试未注册或变更真实系统启动项。

Windows 登录启动、所有全屏应用、真实 AstrBot、用户模型账户、远程 TLS、不同显示缩放与第三方模型仍需在对应环境验证。本版不加入事件记忆、持久聊天历史或语音功能。
